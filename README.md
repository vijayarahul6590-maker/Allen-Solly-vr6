Allen Solly E-Commerce UI 

A Responsive front-end user interface for an e-commerce platform.This project focuses on product presentation,clean layout and interactive ui.

**Note:** This Project  is currently optimized for Desktop/Laptop screen for the best viewing experience.Mobile responsive  will be added  in future updates.

**Live Demo**:Check out the live website here:https://allen-solly-vr6.vercel.app/

**Tech Stack**   
    1. HTML5: Semantic structure and multi-page routing.
    2. CSS3 : Custom styling,Flexbox,layout and responsive UI design.
    3. JavaScript: DOM manipulation, event handling, and interactive user alert.

**Key Features**
    1. Product Grid Layout: Well-structured product display using CSS flexbox for seamless alignment.
    2. Multi-Page Navigation:  Separate interconnected pages for exploring individual  product details.
    3. Interactive Cart Functionality: Dynamic UI noti when user interact with the "Add to Cart" and "Buy Now" buttons.
    4. Clean Code Architecture: Organized folder structure separating style, scripts.
